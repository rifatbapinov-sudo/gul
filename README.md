# Гул

Музыкальный плеер для телефона в стиле концертной афиши.

- Афиша, поиск, альбомы и исполнители — полные треки из открытого каталога Audius.
- «Моя музыка» — плейлист, перенесённый из SoundCloud: официальные загрузки играют через плеер SoundCloud, песни, которых там нет, — с официальных каналов исполнителей на YouTube.
- «Мои файлы» — свои MP3/M4A/FLAC, хранятся только на устройстве и играют без интернета.

Открыть: страница GitHub Pages этого репозитория. На телефоне: «Поделиться» → «На экран Домой».

Запуск на компьютере: `node server.js`.
